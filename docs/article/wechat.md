# 给 DeepSeek Harness 换一套「玻璃皮肤」：dsh-glaze

> 标题备选（挑一个用，或自己改）：
> 1. 我给 DeepSeek Harness 做了套玻璃皮肤，壁纸终于是「透」出来的
> 2. 把 DeepSeek Harness 泡进一层毛玻璃里｜dsh-glaze
> 3. 用了两周，我给 DeepSeek Harness 写了个外观插件

---

用 DeepSeek Harness 写代码久了，会有一个很朴素的念头：**这界面能不能好看一点。**

不是功能不够，是每天盯着同一块白底太久。于是有了这个插件：**dsh-glaze**。

名字里的 glaze 是「给器物上一层玻璃釉」。我想做的不是把界面调透明——那只是把底色变淡；我想让壁纸**真的从一层玻璃后面透出来**。

![浅色主题下的 dsh-glaze](./images/fig-01-light.png)

## 一、先说它和「调透明度」的区别

很多「透明主题」的做法是把背景色加个 alpha，看起来像蒙了层塑料膜。dsh-glaze 用的是浏览器真正的 `backdrop-filter`：整个窗口后面铺着一张壁纸，前面盖一层磨砂玻璃，**模糊是滤镜做出的**，不是画上去的。

所以毛玻璃开关一开一关，差别是这样的：

![左：关闭毛玻璃（壁纸是清晰的）｜右：开启毛玻璃（细节被糊掉）](./images/fig-05-compare.png)

左边能看清壁纸上的同心圆弧，右边只剩柔和的光晕。**文字在右边才真正干净**——因为细节被模糊掉了，不会被壁纸纹理干扰。

这也是我坚持做「开关」的原因：模糊是滤镜，有代价。老机器、远程桌面、或者你就是喜欢清清爽爽，关掉它，插件会退化成纯半透明底色，更省也更快。

## 二、深色也一起做了

同一个插件，切到深色主题不会变成「白玻璃」，色调会跟着换：

![深色主题](./images/fig-02-dark.png)

壁纸、玻璃色调、遮罩都是跟着主题走的，不需要你手动配两套。

## 三、能调什么

所有设置都在 **设置 → 外观** 里，一个页面：

![设置页](./images/fig-03-settings.png)

- **背景图** — PNG / JPEG / WebP / GIF / AVIF / BMP / SVG，单张最大 32 MB
- **界面不透明度** — 0–100% 连续可调，100% 就是原版外观
- **背景模糊** — 0–60px，模糊半径越大细节越少、文字越清楚
- **背景明暗遮罩** — 用主题色压一层，亮色壁纸也能看清字
- **整体压暗** — 独立的黑色遮罩，适合高对比的图
- **填充方式 / 对齐位置** — 铺满、完整显示、原始尺寸、平铺
- **实时预览** — 右上角直接看到叠加结果，不用来回切

底部输入框下面那行统计（轮次 / token / 缓存命中）我也顺手做成了一个小胶囊，不然它悬在玻璃上像被人忘在那儿的文字。

## 四、不想用了，关掉就干净了

这一点我做得比较较真：**关掉总开关，界面必须完全恢复原样**，不能留下半点半透明或者被清空的底色。

![关闭后恢复原版](./images/fig-04-stock.png)

不是把透明度调到 100%，而是真的把插件加的所有东西——玻璃层、遮罩、清底规则、壁纸——全部拆掉。壁纸和数值会留着，下次打开还在。

## 五、怎么装

开源，MIT，代码在 GitHub：

**https://github.com/Yue-Zeyi/dsh-glaze**

安装方式看你的 Harness 版本：

**① 如果插件管理里能填地址**

直接填仓库地址：

```
https://github.com/Yue-Zeyi/dsh-glaze
```

**② 手动装进 profile**

```powershell
$profile = "$env:USERPROFILE\.dsh\profiles\desktop"
cd $profile
npm install github:Yue-Zeyi/dsh-glaze --save-exact
```

然后把 `dsh-glaze` 加进 `package.json` 里 `dsh.profile.bundles` 数组，重启 Harness。

两种方式装完都要**重启一次**，设置页里才会出现「外观」。

## 六、几点说明

- **壁纸只在你本机。** 图片存在 `$DSH_HOME/dsh-glaze/`，不会上传到任何服务器，插件只在本机起几条 HTTP 路由读它。
- **这是第三方插件，不是官方功能。** 出问题可以提 issue。
- **需要 Chromium 111+ / Firefox 113+**（用到了 `color-mix`）。桌面端自带 Electron，满足要求。

## 最后

这个插件是从「每天看着同一块白底有点烦」开始的，后来为了「壁纸到底有没有真的透出来」反复改了很多版——包括一次把整个界面清成透明、一次因为一个反引号导致插件根本没加载。

现在它稳定了，也写得比较克制：能关、能恢复、不偷改你的设置、不联网。

如果它让你的 Harness 好看了一点点，欢迎去仓库点个 star，或者提个 issue 告诉我哪里还能更好。
